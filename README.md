# ⚔️ Acrous Mod

## 📖 English

A **Fabric-based Minecraft horror revenge mod.**

Tame any creature with an apple — but beware... the price is that it will come back for revenge after death.

---

### 🍎 Tame Any Creature
- Hold an **apple** and right-click any creature to tame it
- The creature will recognize you as its owner

### 💀 Death Means Revenge
- If you kill your own tamed creature,
- It will instantly disappear, and your computer will play an eerie voice:
  > **"I will kill you"**
- It will return at the next noon

### 👹 Revenge Monster
- **3000 HP**
- **15 Attack Damage** (❤️×7.5)
- **10 Armor**
- **0.35 Movement Speed** (faster than a normal zombie)
- **64-block Follow Range** (once locked on, it never stops)
- Wields a **Revenge Blade** and wears **Shadow Armor**

### 🔥 Inescapable
- Immune to sunlight and fire
- Follows you across any dimension (except The End)

### 🎮 Creative Mode Restriction
- Cannot switch to Creative Mode while being chased
- The game will automatically switch you back to Survival
- **LAN worlds are exempt from this restriction**

### 🏆 Victory Condition
- Defeat the Ender Dragon
- Jump into the End Portal
- The end poem will be replaced with a credits list

---

### 📥 Installation

1. Install **Fabric Loader 0.19.3**
2. Install **Fabric API**
3. Place the `.jar` file into `.minecraft/mods`
4. Launch the game
